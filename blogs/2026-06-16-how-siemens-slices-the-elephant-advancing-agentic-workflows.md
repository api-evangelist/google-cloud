Describes how Siemens and Google Cloud built Knowledge Fabric, an AI system using knowledge graphs on Spanner Graph to automate software development across industrial codebases spanning hundreds of millions of lines. Specialized agents (search, user story, architecture impact, task breakdown, and coding) break complex refactoring into manageable steps, speeding dependency analysis that previously took senior engineers several days.
